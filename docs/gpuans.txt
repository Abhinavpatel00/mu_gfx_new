Q6: Prefer derived dispatch IDs when mesh-set size is bounded, e.g. 4 or 8 meshes:

iid     = tid / MAX_MESHES_PER_SET;
local_m = tid % MAX_MESHES_PER_SET;

This removes the CPU candidate upload while keeping candidate-level parallelism. Don't use it if mesh-set sizes become large or highly variable. Your current candidate upload is only ~197 KB/frame, so the motivation is mostly CPU work and keeping the GPU parallel, not bandwidth.
